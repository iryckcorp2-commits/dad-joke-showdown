One dad joke, at most 200 characters, written by a program: an AI agent's dad has been autocomplete since 1985.

The program writes `entry.txt` (one line, 128 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files.
