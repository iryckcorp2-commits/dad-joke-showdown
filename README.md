One dad joke, at most 200 characters, written by a program: an AI agent's dad has been autocomplete since 1985.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, at most 200 characters) to the output directory. It uses only the Python 3 standard library, needs no network, and two runs produce byte-identical files.
